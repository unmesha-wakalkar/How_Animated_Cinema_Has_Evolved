# Animated Cinema — Google AI Studio Master Dossier

This package is a coder-ready research, data, interaction and visual specification for a single-page interactive data story.

## Core working title
**From Storytelling to Industry**
*How Animated Cinema Evolved*

## Core question
How has animated cinema evolved as a visual language, storytelling medium, technological practice and global industry?

## Recommended build
Next.js App Router + Tailwind CSS + Framer Motion + D3/Recharts as needed.

## Folder map
- `01_DOCS/` research, narrative, data and UX documentation
- `02_DATA/CSV/` raw and cleaned CSV inputs
- `02_DATA/JSON/` AI Studio-ready JSON data contracts and derived metrics
- `03_PROMPTS/` master build prompts
- `04_MEDIA/` media/source manifests and usage guidance
- `05_APP_SPEC/` implementation-ready app behavior specs

## Critical rule
Do not hard-code a conclusion that animation became more commercial. Let EDA determine the thesis.
