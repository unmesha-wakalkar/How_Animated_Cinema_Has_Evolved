# Motion System

## Scroll
1. Fade/clip reveal for text.
2. Shape morphs for technology transitions.
3. Slow background parallax for cinematic depth.
4. Data elements animate from actual values, not random motion.

## Micro-interactions
- hover poster lift 2–4px
- magnetic/elastic filter chips
- chart points expand on hover
- modal opens with scale/fade, not a hard route change

## Accessibility
Honor `prefers-reduced-motion`. Disable large parallax and morphing while preserving functional state transitions.
