# Visual System

## Direction
**Cinematic minimalism** — precise typography and layout combined with the sense of wonder associated with animation.

## Palette
Use the provided `visual_system.json` as the source of truth. Dark neutral is the structural base; accents indicate semantic states/eras.

## Components
- oversized hero typography
- film-strip/timeline motifs used sparingly
- glassy but restrained modal surfaces
- data particles/nodes
- editorial captions
- monospace metadata labels

## Avoid
- generic dashboard cards everywhere
- excessive gradients
- tiny unreadable labels
- decorative 3D elements unrelated to data
- autoplay audio
