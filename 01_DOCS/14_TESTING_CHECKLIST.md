# Testing Checklist

### Data
- Values in charts can be traced back to JSON source data.
- Missing business data is never displayed as zero.
- Future releases are clearly separated from historical analysis.

### UX
- Search works on desktop and mobile.
- Modal can be opened/closed without losing scroll position.
- Filters can be reset.

### Accessibility
- Keyboard access works for every control.
- Modal focus is trapped.
- Reduced-motion mode works.
- Text contrast passes WCAG-oriented checks.

### Visual
- No generic dashboard appearance.
- Animation supports the narrative.
- Mobile remains coherent rather than becoming a squeezed desktop layout.
