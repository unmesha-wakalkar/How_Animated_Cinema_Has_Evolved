# Data Dictionary

The canonical machine-readable dictionary is `02_DATA/JSON/data_dictionary.json`.

### Highest-value fields for the website
- `Movie_ID`, `TMDB_ID`, `IMDb_ID` — identifiers
- `Movie_Name`, `Original_Title`, `Release_Year`, `Release_Date` — film identity/time
- `Studio`, `All_Production_Companies`, `Country_Origin`, `Original_Language` — industry/geography
- `Animation_Style` — technology/visual-language dimension
- `Genre`, `Theme`, `Overview` — story dimension
- `Budget_Million_USD`, `Box_Office_Million_USD`, `Profitability_ROI` — business dimension
- `TMDB_Rating`, `TMDB_Vote_Count`, `TMDB_Popularity` — audience/reception proxy
- `Belongs_To_Collection`, `Collection_ID` — franchise/series dimension
- `Poster_URL`, `Backdrop_URL`, `TMDB_URL`, `IMDb_URL` — media and source links
