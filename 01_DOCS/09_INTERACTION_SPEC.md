# Interaction Specification

## Core
The visitor can always choose a lens: **Story / Technology / Industry / World**.

## Timeline
- drag/scroll
- decade snap points
- film dots sized by a selected metric
- milestone markers
- click opens a milestone modal

## Film explorer
- search title/original title/director/studio
- filters for decade, style, country, studio, audience and rating
- sort by year, rating, votes, popularity
- click opens dossier

## Comparison
Select up to three films. Open a comparison modal. Use small multiples instead of one overloaded chart.

## Motion
Motion should explain state changes and continuity, not decorate every component.
